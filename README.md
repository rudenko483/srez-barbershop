# СРЕЗ

Демонстрационный сайт барбершопа. Рабочая версия портфолио открывается на [GitHub Pages](https://rudenko483.github.io/srez-barbershop/).

## Передача заказчику

1. Отправьте ссылку на сайт для просмотра.
2. Для передачи управления узнайте имя заказчика в GitHub. На странице репозитория откройте **Settings → Danger Zone → Transfer**, укажите его имя и попросите принять приглашение от GitHub.
3. Вместе проверьте публикацию в **Settings → Pages**. Адрес на GitHub Pages после передачи может измениться. Используйте новый адрес в метаданных, sitemap и ссылках страницы 404.

## Данные для запуска

- Тексты редактируются в соответствующих HTML-файлах. `index.html` — главная, `contacts.html` — контакты и карта, `team.html` — мастера. Картинки лежат рядом с ними.
- Замените примеры отзывов и иллюстрацию команды на материалы барбершопа. Добавьте адрес, контакты и часы работы. Обновите ссылку на карте в `contacts.html` и координаты в `checklist.js`.
- Для записи подключите сервис заказчика. В `booking.html` показана демоформа, а сообщение благодарности подтверждает только просмотр выбора. Согласуйте срок ответа до публикации обещания клиентам.
- Для Google Analytics укажите идентификатор потока GA4 в `checklist.js`. Тег загружается после согласия посетителя. Перед запуском проверьте настройку и актуализируйте страницу конфиденциальности под реальный сбор данных.
- `robots.txt` лежит в папке проекта. Поисковики читают этот файл с корня домена. На отдельном домене разместите его в корне и обновите адрес sitemap. Текущий sitemap также можно указать в панели поисковика вручную.
